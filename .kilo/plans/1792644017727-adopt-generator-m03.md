# Adopt kvk generator library, add map m03

## Goal
Copy the procedural mesh `generator` package from `/mnt/main/code/kvk` into kogl, create a new map `m03` showcasing generated meshes, and load it alongside m02 (offset in world space so scenes don't overlap).

## Context (verified)
- kvk generator lives at `/mnt/main/code/kvk/modules/src/main/kotlin/generator/` (79 files, package `generator`).
- Its only external imports are `algebra.Vector2`, `algebra.Vector3`, `algebra.toRadians` (Vector2/Vector3/Common are byte-identical between repos — Matrix2/3/4 differ but are NOT imported by generator) and `mesh.OBJMesh` / `mesh.ObjTriangleIndices` (same constructor API in kogl's `modules/src/main/kotlin/mesh/Mesh.kt:49`).
- `generator/ObjAdapter.kt` already provides `GeneratorMesh.toObjMesh(name): OBJMesh`.
- kogl `Drawable` (`modules/src/main/kotlin/graph/Drawable.kt:29`) renders `SeparatedArraysMesh` via `ArrayMeshBuffer`, so each generated mesh must be wrapped: `SeparatedArraysMesh(gen.toObjMesh("name"))` — same pattern `Storage` uses (`map/Storage.kt:45`).
- Map pattern reference: `kogl/src/main/kotlin/kogl/maps/m02.kt` (uses `buildLocale`, `stateGroup`, `offset`, `spinableDrawable`, `flyaroundDrawable` DSL from `graphdsl`).
- Loading site: `kogl/src/main/kotlin/kogl/Window.kt:89-92`.

## Tasks
1. **Copy generator package**: `cp -r /mnt/main/code/kvk/modules/src/main/kotlin/generator /mnt/main/code/kogl/modules/src/main/kotlin/generator`. No edits expected; if compile errors appear, adapt to kogl style per AGENTS.md (private members `_`, public `m`-prefixed, no ternaries, braced ifs, no trailing semicolons).
2. **Create `kogl/src/main/kotlin/kogl/maps/m03.kt`** with `fun m03(): List<Locale>`:
   - Same imports as m02 plus `import generator.*` and `import mesh.*`.
   - Reuse the `flatshadeProgram` pattern from m02.
   - Build an example scene using a few generators, e.g.:
     - `IcoSphereMesh(radius = 2.0f, subdivisions = 2)` (check constructor signatures when writing)
     - `TorusMesh(...)`
     - `CapsuleMesh(...)` or `TubeMesh(KnotPath(...))`
     - `BoxMesh(...)` / `PlaneMesh(...)` as a ground plane
   - Convert each: `SeparatedArraysMesh(TorusMesh(...).toObjMesh("torus"))`.
   - Place drawables via `offset`/`rotate` transforms with distinct colors and `anglSpeed` values, modeled on m02's layout.
   - Locale origin offset from m02's origin, e.g. `Vector3(60.0f, 0.0f, 0.0f)`, so both scenes are visible without overlap.
3. **Load in `kogl/src/main/kotlin/kogl/Window.kt`** after the existing m02 block (line ~89):
   ```kotlin
   with(mainScene) {
       val m3 = kogl.maps.m03()
       addLocales(m3)
   }
   ```
4. **Verify**: `./gradlew build` compiles (tests: `./gradlew build` runs module tests too). Note: the app opens a GLFW window — cannot be visually run headless here; compile + tests are the validation gate. Optionally port kvk's `modules/src/test/kotlin/generator/` tests as a smoke check.

## Risks / notes
- Generator file count is large; if any file uses a Matrix API that diverged between repos, fix locally in the copied file (expected: none — imports checked).
- Constructor parameter names/defaults in generator files must be read before writing m03 — do not guess signatures.
- Keep m02 loading intact; m03 is additive.
