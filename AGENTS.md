# Rules  
- Use COMMANDMENTS.md to understand for what is for.
- If plan is implemented give good middle sized commit message in MD format.

# Code  
- Start all private class members from "_".  
- Start all other class members from "m" in camelCase.  
- No trailing semicolons.  
- No ternary operators, only explicit "if" statements.  
- No "short" if statments, always brace-enclosed.  
- Use maximum verbose lambda syntax.
