## Kotlin scenegraph.

This is a scene graph rendering application inspired by some ideas from vsg (osg) and java3d scenegraphs.

For references you can came across Vulkan Scene Graph - https://github.com/vsg-dev/VulkanSceneGraph or  
Java 3D
specification - https://docs.oracle.com/cd/E17802_01/j2se/javase/technologies/desktop/java3d/forDevelopers/j3dguide/j3dTOC.doc.html

### Run

```gradle kogl:run```
